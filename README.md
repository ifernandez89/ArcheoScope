# Archeoscope: The Forgotten Relics

An immersive 3D archaeological exploration game built with Next.js, Three.js and React Three Fiber.

Explore ancient civilizations, discover forgotten relics, and uncover the mysteries of the world's most enigmatic archaeological sites.

## Features

- 🌍 Interactive 3D globe with real archaeological sites
- 🛸 UFO avatar with special abilities
- 🌌 Realistic star map with 83,000+ stars and 27 constellations
- 🌙 Night sky observatory scene
- 📅 Maya Cholq'ij calendar and Babylonian sexagesimal system
- 🔭 Real-time astronomical calculations
- 📱 Mobile-optimized with touch controls

## Tech Stack

- Next.js 14 (App Router)
- Three.js + React Three Fiber
- TypeScript
- Bun

## Development

```bash
cd viewer3d
bun install
bun run dev
```
